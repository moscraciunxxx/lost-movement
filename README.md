## How to run

Requires Node.js 20+.

```bash
git clone https://github.com/moscraciunxxx/lost-movement.git
cd lost-movement
npm install
npm test
npm run dev
```

Open `http://127.0.0.1:5173`. Click **Tonight’s attic**.

The full source is committed locally and waiting on one `git push` from the author machine (GitHub MCP created this repo; SSH from that Mac has no user key yet).
