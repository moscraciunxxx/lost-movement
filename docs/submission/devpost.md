# Devpost (secondary)

**Project name:** Lost Movement

**Tagline:** A museum of the work you never finished.

**Description:**

Lost Movement hangs the drafts you abandoned. Click Tonight’s attic. A filament finds a brass plaque. The first sentence types on and stops mid-line. Seven rooms, never a file list. A printable house program. Nothing leaves the machine.

Built *in* Agent Orchestrator (aoagents.dev). The demo video shows the Kanban and three live sessions. Lost Movement is not an AO clone.
