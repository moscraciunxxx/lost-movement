**The Orchestra** is Agent Orchestrator (AO)'s first online hackathon.

- Devpost: https://ao-orchestra.devpost.com (challenge_id `30986`)

- AO X: https://x.com/aoagents
- Prateek Karnal X: https://x.com/agent_wrapper

**AO is not Arweave AO.** Agent Orchestrator is a desktop/local agent IDE: a Kanban supervisor for parallel coding agents (Claude Code, Codex, Cursor, Grok, OpenCode, …) in isolated git worktrees, with CI/review/merge feedback loops.

## Tagline from organizers

> Build anything you want using AO as your coding workspace. Your project does **not** need to be about AO. AO is **how** you build: plan, delegate, code, review, test, and ship with agents running on your machine.

## Winning strategy (for this specific jury)

This is judged by the **AO creators**. Criterion #1 is *proof you used their product as a workspace*. Criterion #2 is a finished demo. Creativity and a clean story win the rest.

Do **not** build a clone of AO. Do **not** ship a slide deck. Ship one complete, locally runnable, visually memorable product. Make AO usage obvious: Kanban cards, parallel sessions, reviews, branches.

Suggested attack (Design may override with a stronger idea):

**Build a surprising, finished product that is *not* “another agent dashboard.”** Prefer local-first, demoable in 90 seconds, with a soundtrack/visual hook that matches the Orchestra name *without* being a gimmick wrapper around AO.

Document every AO session as first-class evidence (`docs/ao-usage.md`, screenshots folder, demo script that opens the Kanban).
